# Yojith Thati — Personal Portfolio

A warm, cricket-inspired personal portfolio built with HTML, CSS and JavaScript.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Editing content

- Update project cards in the `projects` array in `script.js`.
- Update learning progress values in `styles.css` (`--progress`).
- Update `contactEmail` in `script.js` to change the contact destination.
